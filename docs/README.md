# Moon Game Documentation

This folder holds project guidance for AI-assisted Unity development.

## Architecture

- `architecture/core_paradigm.md` defines the Core-vs-Domain architecture.
- `architecture/event_bus.md` documents the shared Core event bus API and lifetime rules.
- `architecture/decisions/ADR-0001-player-controller.md` records the accepted player-controller architecture decision.

## Roadmaps

- `roadmaps/player-controller.md` is the live roadmap for replacing the whitebox Starter Assets controller with project-owned player systems.

## Domain routing

- `domains/*_rules.md` contains route-specific rules loaded for domain work.

## Archive

- `archive/ai-conversations/` keeps recovered planning context from prior AI conversations.
- Archive files are intentionally ignored by Git because they are large context dumps, not source-of-truth documentation.
